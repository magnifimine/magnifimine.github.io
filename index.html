Перед установкой

Основной лаунчер — выполните шаги по порядку

1
Скачайте компоненты
Visual C++ Redistributable x64 — без него лаунчер может не запуститься.
Скачать компоненты
2
Установите компоненты
Запустите скачанный vc_redist.x64.exe и следуйте установщику (галочка «Я согласен» → Установить).
3
Скачайте лаунчер
После установки компонентов можно качать основной лаунчер.
Скачать лаунчер
Важно: если лаунчер уже запускался ранее и всё работает — компоненты можно не устанавливать повторно. Если после установки лаунчер не открывается, перезагрузите ПК.
